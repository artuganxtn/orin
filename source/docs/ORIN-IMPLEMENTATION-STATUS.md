# ORIN — حالة التنفيذ

هذه نسخة ويب محلية قابلة للبناء، ولم تُنشر على الموقع بعد. وهي لا تمثل اكتمال جميع متطلبات تطبيقَي Android وiOS.

## ما نُفّذ

- طبقة Dark Mode بألوان Navy/Blue/Cyan، مع فصل توثيق LightThemeTokens وDarkThemeTokens. ملفات CSS الأصلية للوضع النهاري والشعار الأساسي مطابقة لنسخة المصدر السابقة بالبايت.
- صفحات كاملة وعناوين URL وسجل رجوع حقيقي للإعدادات، المظهر، الإشعارات، الأمان، تفاصيل العقود والإيصالات والأقسام الجديدة. الروابط تحفظ الوجهة عند تسجيل الدخول.
- مركز إشعارات بسبع فئات وحالة قراءة مستقلة لكل مستخدم وعدّاد من الخادم، قراءة الكل، تحميل المزيد، فلترة الصلاحية والملكية والتفضيلات. دعم أفضل محاولة لـApp Badge في المتصفحات التي تدعمه.
- لوحة حملات داخل التطبيق: مسودة، معاينة العدد والجمهور، تأكيد، إرسال وإلغاء، سجل تدقيق ومنع التكرار عند تزامن الطلبات. استهداف البلد والفئة واللغة ومستخدمين محددين، مع موافقة تسويقية افتراضيًا غير مفعّلة.
- أيقونات الويب وAndroid وiOS، موارد Adaptive Icon وNotification Icon، نسخ الرمز والشعار الفاتحة والداكنة والأحادية، وشاشة افتتاح قصيرة في وضع التطبيق المثبّت.
- أربعة أصوات أصلية مولّدة للمشروع مع WAV/OGG/CAF، معاينة عند الضغط، تفضيلات الصوت والاهتزاز والتسويق، احترام تقليل الحركة، وحالات تحميل/فراغ/خطأ/نجاح.
- توثيق نظام التصميم والأصول، وترحيل قاعدة البيانات `0003_orin_notification_identity.sql`.

## ما يحتاج ربطًا أو تحققًا إضافيًا

| الجزء | الحالة الفعلية |
|---|---|
| Push عبر Firebase/APNs | غير مربوط؛ لا توجد خدمة إرسال أو تسجيل أجهزة/رموز Push أو Service Worker لاستقبال Push |
| Android/iOS | ملفات الأصول جاهزة، لكن لا توجد مشاريع أصلية أو ملفات تثبيت أو اختبار أجهزة |
| الأصوات والـBadge خارج التطبيق | غير مُثبتة على النظام؛ تعتمد على الربط الأصلي وقيود المنصة |
| جدولة الحملات | البداية والانتهاء محفوظان، لكن لا يوجد عامل جدولة يعمل والتطبيق مغلق؛ الإرسال يدوي بعد موعد البداية |
| استهداف الوكلاء والمستخدمين الموثقين | غير متاح لعدم وجود مصدر موثوق لهذه الحالات في البنية الحالية |
| 2FA والأجهزة وتذاكر الدعم والإحالات | صفحات ومسارات توضح الحالة؛ لا توجد خدمات تسجيل TOTP أو إدارة جلسات أو تذاكر أو مكافآت وهمية |
| تنبيهات الدخول/الأمان | الفئة والصلاحيات جاهزة؛ توليد أحداث الدخول يتطلب ربط مزوّد الهوية |
| إيداع/سحب حقيقي | غير متاح؛ المشروع ما زال بيئة محاكاة معلنة كما كان |
| Visual Regression كامل | لم يكتمل؛ سياسة المتصفح منعت التقاط المرجع المقارن. فحص ثبات ملفات Light اجتاز، لكنه لا يثبت التطابق البصري لكل شاشة |
| النشر | متوقف بسبب اتصال مستودع المصدر؛ محاولة الصلاحيات الموسعة السابقة رُفضت آليًا، ولم تُتجاوز القيود |

## التحقق المنجز

- 34 اختبارًا ناجحًا: 14 للمحرك المالي الافتراضي، 11 للإعدادات، 7 للإشعارات والحملات والروابط، واختباران لثبات Light وتباين Dark.
- `npx tsc --noEmit`: ناجح.
- بناء الإنتاج: ناجح.
- معاينة فعلية لصفحة المظهر الداكن، فتح الإعدادات كصفحة مستقلة، الرجوع، ومركز الإشعارات في حالة عدم تسجيل الدخول. الصورة: `docs/orin-dark-preview.jpg`.
- اختبارات الخادم تشمل عزل البيانات، احترام الموافقات، صلاحيات الإدارة، التنبيهات الأمنية، الإشعارات القديمة خارج أول صفحة، ومنع الإرسال المتزامن المكرر.

لإعادة الاختبارات: شغّل ملفات `tests/engine.test.mjs` و`tests/settings.test.mjs` و`tests/notifications.test.mjs` و`tests/theme.test.mjs` بواسطة `node --experimental-strip-types`، ثم فحص TypeScript وبناء المشروع.

يجب نشر هذه الشفرة وترحيل قاعدة البيانات عبر مسار Sites المعتمد قبل اعتبار الموقع المنشور مُحدّثًا. لا يُغيّر هذا العمل صلاحيات مشاركة الموقع الحالي.
