# قفل الرجوع إلى ORIN بواسطة Android

اكتمل بناء هذا المصدر وترجمته إلى DEX وتجميعه مع الويب الجديد في ملف **غير موقّع وغير قابل للتثبيت**: `../../additional-builds/ORIN-Android-1.6.2-Updated-UNSIGNED-NOT-INSTALLABLE.apk`. تعذر توقيع إصدار متوافق بمواد التوقيع الموجودة في الأصل؛ التفاصيل في `../../FULL-UPDATE-BUILD-REPORT.md`. لم يُشغّل تطبيق أو محاكي أو اختبار. نسخ APK الأصلية محفوظة كما هي ولا تحتوي هذه الإضافة.

## السلوك المقصود في المصدر

- بعد بقاء التطبيق خارج الواجهة لأكثر من 15 دقيقة، يُحجب المحتوى عند العودة حتى ينجح التحقق النظامي.
- هذا ليس مؤقتًا لمدة الاستخدام: لا يُقفل التطبيق لمجرد استعماله بنشاط أكثر من 15 دقيقة.
- تُخفى واجهة WebView أثناء مغادرة التطبيق. يستخدم قرار الغياب ساعة Android الرتيبة `elapsedRealtime` ورقم إقلاع الجهاز، لا ساعة يمكن للمستخدم تغييرها.
- يبقى القفل محفوظًا عند الإلغاء أو فشل البصمة أو الضغط على الرجوع. عند إعادة تشغيل الجهاز أو موت العملية بلا نقطة غياب موثوقة، يُطلب التحقق احترازيًا.
- التحقق من Android نفسه: `BiometricPrompt` في API 28 فما فوق؛ في API 29/30+ يسمح النظام أيضًا برمز/نمط/كلمة مرور قفل الجهاز. يتوفر مسار قفل الجهاز النظامي في API 26/27 وعند تعذر البصمة.
- لا تُحفظ بصمة أو PIN جديد داخل التطبيق، ولا تُطلب صلاحية جديدة؛ أذونات البصمة موجودة أصلًا في البيان.
- عند عدم وجود قفل شاشة آمن، لا يدّعي التطبيق الحماية ولا يكشف المحتوى المقفول. يشرح الحاجة إلى إعداد قفل الجهاز؛ زر الإعدادات يفتح شاشة Android فقط بعد ضغط المستخدم، ولا يغيّر الإعدادات بنفسه.
- لا يغيّر هذا القفل هوية الحساب أو صلاحيات الخادم، ولا يعوّض تسجيل الدخول أو التحقق المالي.
- لا توجد `FLAG_SECURE` عامة جديدة تمنع صور الإيصالات أو مشاركتها أثناء الفتح العادي. إذا تجاوز اختيار ملف/حفظ تصدير حد الغياب، تُلغى النتيجة حتى لا تتجاوز القفل؛ يمكن إعادة الطلب بعد فتح الجهاز.

## نطاق التعديل

- إضافة `src/com/orin/app/security/AppLockController.java`.
- وصلات محدودة داخل `MainActivity.java` للظهور/الإخفاء، بدء WebView بعد السماح، التحقق من نتائج أنشطة النظام وحماية الأوامر أثناء القفل.
- لم تتغير هوية `com.orin.app` أو أصول الهوية الأصلية أو الدومين أو مفاتيح التوقيع أو الشعار أو بطاقة الرصيد.
- بقيت آليات ORIN السابقة منفصلة. لا يستطيع نجاح PIN داخلي أو JavaScript تجاوز هذا القفل النظامي.

## حدود المراجعة

رُوجعت مسارات الإلغاء، إعادة الإنشاء، الرجوع، فشل حفظ الحالة، نتيجة تحقق متأخرة، وغياب إعداد قفل الجهاز قراءةً فقط. لم نثبت تشغيلها على جهاز فعلي. يلزم التحقق على جهاز Android يملكه صاحب المشروع بعد البناء؛ خصوصًا اختلاف واجهة البصمة بين إصدارات Android والشركات المصنّعة.

مراجع API الرسمية التي استُخدمت في إعداد المصدر:

- [Android BiometricPrompt.Builder](https://developer.android.com/reference/android/hardware/biometrics/BiometricPrompt.Builder)
- [Android KeyguardManager](https://developer.android.com/reference/android/app/KeyguardManager)
